# The GM's backup

The GM's page holds a copy of everything in the game, players' private things included, so nothing is
lost when a browser is cleared, and the GM can reach a private thing in an emergency. Opened by Bill,
2026-11-24: "I think we have some amount of private data that's not shared with the GM; let's fix that so
the GM has a full backup of everything in the game but can't look at 'private' things without switching
to that player."

## What's private today

Kept on a player's page alone, never sent, and lost when that browser is cleared:

- **"Just me" notes** (`m:` records; `carves/done/organizing.md`, Item 1: "Player's page only").
- **A player's drawers** (their `desk` record; Item 3: "Player only").
- **A player's own Boot Hill**: their buried "just me" notes and torn tapes.
- **Torn tapes** (`carves/done/tapes.md`): each page's own.

Seat things (the view, tied dockets, the graveyard browsed) are views, not game data, and stay out.

## Item 1

The GM's page keeps a copy of each player's private things, sent to it alone, and doesn't show them
(Item 3 is how the GM looks). This reverses part of the rulings quoted above: "just me" no longer means the
GM's browser never holds it. It means the table never sees it, and the GM sees it only by choosing to
(Item 5 says so to the players).

## Item 2

A player who joins from a cleared or new browser gets their private things back from the GM's copy.

## Item 3

Viewing as a player with "You are", the GM sees that player's "just me" notes and drawers as they do, and
can share a note with the GM or reassign it from there (`carves/fixes.md`, Item 11).

## Item 4

A checkpoint, a saved game and an export carry the backup, so they hold everything.

## Item 5

The "How to use the table" page says at its top that everything is shared with the GM's browser and
visible to the GM at the GM's discretion. That's the disclaimer, said once: the "Just me" choice keeps its
label and nothing else in the table's text repeats it.

## Item 6

A new game's table starts with the "How to use the table" page on it, and nothing else, so the
disclaimer is the first thing on an empty table. (Today New game starts an empty table: `specs/games.md`.)

## Decisions

DECIDED (Bill, 2026-11-24), on Daneel's proposal: restoring a player's fresh browser from the copy, the GM
seeing a player's private things by viewing as them, reassigning from there, and saved games and exports
carrying the backup: "1-4 are good". The disclaimer: "We can keep the 'just me' label but include a note
at the top of the 'how to play the table' card that all information is shared with the GM's browser and
visible to the GM at their discretion. That's the disclaimer and we don't need to repeat it anywhere else
in the table text." The empty table: "Empty tables can start with just the 'how to play' card on them."

Daneel's note, for the record: the copy is the GM's discretion, not the wire's. Encrypting it with the
player's key wouldn't help, since the key lives in the same browser and would be lost with it.

DECIDED (Bill, 2026-11-24): **torn tapes are in the backup** too ("Yes, back them up"), reversing in part the tapes
carve's "each page's own": the table still never sees another page's torn tape.

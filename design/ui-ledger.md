# UI: the Ledger
**Requirements:** R132, R141, R457, R485

```
 ┌─cloth spine─┬──────────────────────────────────────────────┐
 │             │  The 11-08 playtest              Saved 18:36 │
 │   Ledger    │  ─────────────────────────────────────────── │
 │             │  Checkpoint    Export    Import    New game  │  ← written on the page
 │             │  ─────────────────────────────────────────── │
 │             │  Checkpoints              │ when             │
 │             │  End of conflict, round 2 │ Nov 11 18:36     │
 │             │  Two rolls in             │ Nov 11 18:30     │
 │             │  ─────────────────────────┼───────────────── │
 │             │  Games                    │ opened           │

 └─────────────┴──────────────────────────────────────────────┘
```

- Ruled columns; entries are written in the book; each line is its own target.
- A player's Ledger shows the name, the save status, Export, and Tables joined (R485).
- Tables joined, under Games (or alone on a player's page): each copy of a table this browser joined,
  its room, the name it was joined as, and when last opened. A shift-click on an entry arms it red ("Shift-click again to delete
  forever"), the way Boot Hill does (R457); the one on the table can't be armed.
